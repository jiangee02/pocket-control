# 随手控 · 设计说明

本文记录界面为什么长这样，以及实现时使用的颜色、字号与形状规则。改动界面之前先读这里。

## 方向

画面是主角，界面是工具。

- 连接页只做一件事：让用户看清地址、输入 PIN、连上去。
- 连上之后装饰退场，只剩顶栏、画面和按键条。
- 不用卡片堆叠、大标题配眉题、彩色光晕、玻璃拟态、渐变文字和装饰性图标。

## 两端的组成

| | 主控网页 | 被控端 App |
|---|---|---|
| 底色 | 页面 `#F4F7FB`，顶栏与卡片 `#FFFFFF`，画面区 `#0A0F16` | 页面 `#F4F7FB`，卡片 `#FFFFFF` |
| 强调色 | 蓝青只用于状态、焦点、进度和主按钮 | 主色 `#1657FD`，青色 `#2CC6FD` 表示在线 / 成功 |
| 布局 | 顶栏 52px，按键条 62px，行距松 | 卡片 14dp 圆角，18dp 外边距 |

两端共用一套语言：同一张图标、同一段蓝到青、同一套圆角与 1px 描边、数字一律等宽。

App 首页按操作顺序排列：

1. **Shizuku 授权**：卡片右上角是状态灯与短状态（已授权 / 待授权 / 未运行），未授权时显示「去授权」。
2. **会话**：开始 / 停止会话放最上面；会话开始后，卡片下半部分展开主控连接（地址、PIN、二维码、复制按钮）。
3. **会话设置**：画质、端口、连接方式、自动关闭无障碍；配对 PIN 与「随机生成」同一行。
4. **运行日志**：只记录关键事件，可一键复制。

## 色彩

```
主色      #1657FD   主按钮、焦点、当前档位
青色      #2CC6FD   在线点、进度、图标亮端
画面      #0A0F16   仅画面区与独立窗口悬浮栏
浅面      #F4F7FB → #FFFFFF
描边      #E4EAF2
正文      #16202E
次要      #647286
危险      #C9404F
成功      #06775A
待处理    #B7791F
空闲      #93A1B3
```

- 蓝青只表示状态、焦点、进度和主操作，不做装饰性渐变块。
- 不用彩色外发光；焦点用描边或偏移环。
- 浅色界面上的正文与次要文字对比度不低于 4.5:1。
- 深色只出现在画面区和独立窗口悬浮栏，界面其余部分是浅色。

## 字体

- 中文使用系统字体栈：MiSans → HarmonyOS Sans SC → PingFang SC → 微软雅黑。
- 等宽只给 PIN、IP 与端口、编码耗时、码率、分辨率、日志。
- 字重只用 400 和 500，700 只给 PIN 与关键数字。
- App 字号：品牌 20，卡片标题 16，正文 14，说明 12；网页正文 12.5–13.5。
- 不用大字距英文小标签做「眉题」。

## 形状与层级

- 圆角：控件 10–12dp，卡片 14–18dp，大面板 20–22dp，圆形只给状态点。
- 层级只靠底色差、1px 描边和一层柔和投影，不叠多层阴影，不做卡片套卡片。
- 网页连接卡是亮底上的一张白卡，图标外圈有一道蓝青轨道；连上后画面接管。

## 动效

- 全站只有连接页图标外圈轨道持续旋转（11 秒一圈），以及连接时卡片淡入。
- 其余都是 200–400ms 的功能性过渡：悬停、按下、面板滑出、状态切换。
- 不动画宽高与阴影；尊重 `prefers-reduced-motion`。

## 图标

- 蓝到青渐变的圆角方形，中间是白色手机与环绕轨道。
- 桌面自适应图标、App 首页标记、网页 favicon 使用同一套位图。
- 自适应图标前景只占画布 43%，四周留白，避免桌面裁切后铺满方块。

## 文案

- 说事实，不用感叹号，不写「轻松」「一键搞定」。
- 数字和单位贴在一起：`1080×2400`、`12.4 Mbps`、`编码 96ms`。
- 按钮用动词：开始会话、去授权、随机生成、复制。
